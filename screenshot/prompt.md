# AI Prompts Used During Development

## Prompt 1 - Landing Page Structure

Create a professional and responsive landing page for Prodesk IT using HTML, CSS and JavaScript. Include a navbar, hero section, services section with three service cards, CTA button and footer.

## Prompt 2 - Responsive Design

Help me make the Prodesk IT landing page responsive for desktop and mobile devices using CSS Flexbox and CSS Grid without using Bootstrap or other UI frameworks.

## Prompt 3 - Dark and Light Mode

Help me implement a dark and light mode toggle using vanilla JavaScript by adding and removing a CSS class on the body element.

## Prompt 4 - Responsive Navigation

Help me create a responsive mobile navigation menu using HTML, CSS and JavaScript.

## Prompt 5 - Hover Effects

Help me add professional hover effects and micro-interactions to CTA buttons and service cards using CSS.

## AI Usage

AI tools were used during development to assist with HTML, CSS and JavaScript implementation, responsive design, debugging, and improving the functionality of the landing page. The generated suggestions and code were reviewed, modified where required, and tested before being integrated into the project.
