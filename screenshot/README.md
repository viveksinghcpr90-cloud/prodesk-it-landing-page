# Prodesk IT - Digital Solutions Landing Page

A responsive and modern landing page developed for Prodesk IT using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Website](https://prodesk-it-landing-page-wheat.vercel.app)

## 📌 Project Overview

Prodesk IT is a responsive business landing page designed to present digital services in a clean and professional interface.

The website focuses on:

- Responsive design for desktop, tablet, and mobile screens
- Clean navigation and section-based layout
- Light and dark theme support
- Interactive mobile navigation
- Service and business information
- Responsive cards, buttons, and call-to-action sections

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media Queries
- DOM Manipulation
- Git & GitHub
- Vercel

## ✨ Key Features

### 1. Responsive Layout

The website adapts its layout according to different screen sizes using CSS Grid, Flexbox, and media queries.

### 2. Light and Dark Mode

Users can switch between light and dark themes using the theme toggle button.

### 3. Responsive Navigation

On smaller screens, the navigation links are converted into a mobile menu.

### 4. Service Sections

The landing page includes dedicated sections for:

- Website Development
- SEO Optimization
- Digital Marketing

### 5. Interactive UI

Buttons, navigation links, cards, and other interface elements include hover and transition effects.

### 6. Mobile Menu

The mobile navigation can be opened and closed using the menu button.

### 7. Sticky Navigation

The navigation bar remains accessible while scrolling through the page.
